# Security

This experimental application is intended for a trusted local machine or private
network. Its services bind to loopback by default. It does not provide public
multi-user authentication. Do not expose the application, executor or ComfyUI
directly to the internet. Keep project databases on a local filesystem.

For a sensitive issue, use the repository's private vulnerability reporting option
if enabled. Otherwise contact the maintainer privately through their GitHub
profile before sharing exploit details. Do not put credentials, private media or
personal data in public issues. Include the affected source revision, reproduction
steps and impact with sensitive values removed.

No supported-version window or response-time guarantee is established for this
alpha. Review dependencies and model terms before deployment or redistribution.
